## Matlab scripts

### GEN_11ad_SC_FRAMES.m
File used to generate IQ samples for the USRP RFNoC system. It is based on the 802.11ad Transmitter Spectral Emission Mask Testing script from MATLAB library Baseband Waveform Generation.
The waveform generator can be configured to generate one or more packets with idle time between each packet.

### PD_read_out_file.m
Packet detector plot output file
